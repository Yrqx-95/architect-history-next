## Purpose

This log records source-safe image review decisions for the Graduation Inspiration Library case dataset. The rule is conservative: use only exact project/facility images with clear source and license metadata, preferably Wikimedia Commons or already-local verified assets. Do not use unclear media reposts, Pinterest, Getty, or official project images unless reuse is clearly allowed.

## Implementation Notes

- `src/app/api/image-proxy/route.ts` now returns a visible PNG placeholder when an upstream image fetch fails or is rate-limited, instead of returning a transparent 1x1 pixel.
- `src/components/GraduationInspirationApp.tsx` bypasses Next image optimization for proxied case images to avoid caching transient fallback pixels.
- `scripts/localize-graduation-case-images.mjs` makes image localization repeatable and keeps source/license/credit fields intact.
- `scripts/optimize-graduation-case-images.mjs` resizes localized JPEGs and strips EXIF/XMP/comment metadata without adding a new dependency.
- `src/app/globals.css` now applies `animation-fill-mode: both` to page-enter animations so detail-page content remains painted in screenshot/headless environments after the enter animation.
- Detail-page case images use full-image containment while compact cards keep cover cropping, so portrait images are inspectable on detail pages without breaking card grids.
