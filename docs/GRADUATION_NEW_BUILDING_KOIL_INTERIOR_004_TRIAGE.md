# G6 KOIL interior batch 004 审核记录

日期：2026-07-12

## 结论

- 本批只包含 `CASE-035 KOIL Kashiwa-no-ha Open Innovation Lab`。
- CASE 对象是 Naruse Inokuma Architects 于 2014 年完成的 2,576 m² 创新中心室内设计，不是由其独立设计的新建筑本体。
- 当前 Commons 图片拍摄的是明确标有 `KOIL GARDEN by MITSUI FUDOSAN` 的另一处低层外部设施，不是 2014 年 KOIL 室内项目。
- 本批迁移批准数为 0；保留 CASE 路由和毕业分析，不错误建立 canonical building。

## 身份边界

Naruse Inokuma 官方作品页和事务所履历确认：

- 项目：KOIL 柏の葉オープンイノベーションラボ；
- 分类：Shared Space；
- 范围：イノベーションセンター内装 设计与监理；
- 面积：2,576 m²；
- 时间：2014 年 4 月；
- 地点：千叶县柏市。

因此将它直接写为 `buildings` 会把室内设计者错误地变成整栋宿主建筑的建筑师。除非未来建立“室内项目 linked to host building”的明确实体层，否则不迁移。

## 图片审核

- `KOIL_GARDEN.jpg`：1924×1080，Souka Kinmei 自有作品，CC0。

- 人工查看确认画面为带有 KOIL GARDEN 标识的低层外部园区与咖啡空间，并非官方作品页中的创新中心室内。
- 权利安全不能替代对象正确性；当前图片不得成为 CASE-035 canonical cover。
