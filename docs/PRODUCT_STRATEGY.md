# PRODUCT_STRATEGY.md — Archistory 产品路线

> 最后更新：2026-05-31

## 产品定位

Archistory 的目标不是建筑作品展示站、事务所官网或作品集网站，而是一个建筑史知识网络：

```
Architects × Buildings × Styles × Movements × Regions × Timeline
```

核心价值是帮助用户理解建筑史中的关系，而不只是查到建筑名、建筑师名或图片。

## 北极星

用户进入任一建筑师、建筑、风格、地区或时期后，都应该能回答：

- 它位于哪个历史时期？
- 它从哪些风格、人物或地区经验中产生？
- 它影响了哪些建筑师、作品或流派？
- 它为什么重要？
- 下一步应该读什么？

## 参考产品分工

- ArchDaily：项目资料密度、建筑类型和地点索引。
- Dezeen：短导航和媒体传播效率，但不作为知识结构参考。
- Divisare：建筑 atlas 与主题策展路径。
- The Met Timeline：时间、地域、主题、对象共同组织历史。
- Smarthistory：面向学习者的作品解释方式。
- Wikipedia：实体页、infobox、分类、引用。
- Wikidata：稳定实体 ID、结构化关系、外部 ID、来源支持。

## P0 产品方向

### 1. 时间轴双模式

为什么做：建筑史首先是时间关系。只做 decade card 会有密度，但缺少古典、哥特、文艺复兴、现代主义之间的连续叙事。

解决问题：用户无法理解历史演化，只能看到某十年有哪些作品。

用户价值：先建立历史框架，再进入具体作品。

实现策略：

- `Narrative timeline`：时期、风格、建筑师、代表作的连续阅读。
- `Decade atlas`：按十年快速查找具体建筑。
- 后续再加入拖拽、缩放、建筑师 lifespan bar。

### 2. 关系数据模型

为什么做：没有关系数据，就没有 Architecture Knowledge Graph。

解决问题：建筑师、建筑、风格、时代互相孤立。

用户价值：能看到师承、影响、合作、同代、风格演化。

第一批关系类型：

- `influenced_by`
- `influenced`
- `studied_under`
- `taught`
- `collaborated_with`
- `worked_for`
- `designed`
- `associated_with_style`
- `belongs_to_period`
- `reacted_against`
- `evolved_into`

当前进展：已建立仓库优先的 `Architect Relationship Overlay` 第一版，并先在建筑师详情页显示人物关系。建筑详情页已新增基于现有数据实时生成的 `Reading paths`，把作者、时代、风格、地域和相近作品组织成下一步阅读入口。下一步应把同一关系模型扩展到风格详情页、时代详情页和专门的 `/graph` 视图。

### 3. 建筑师页升级

为什么做：建筑师页是知识网络最重要的节点。

解决问题：当前人物页仍偏简介 + 作品列表。

用户价值：理解人物在历史中的位置、思想、师承、影响和代表作。

页面必须逐步具备：

- 生平
- 思想线索
- 师承关系
- 影响来源
- 影响对象
- 理论贡献
- 代表作品分析
- 阅读路径

### 4. 建筑页升级

为什么做：建筑作品不能只是 metadata 和图片。

解决问题：作品页缺少历史解释和空间分析。

用户价值：理解作品为何重要，而不只是看图。

页面必须逐步具备：

- 时代背景
- 建设背景
- 设计理念
- 空间特点
- 结构体系
- 材料体系
- 历史影响
- 争议与评价

### 5. 图片可信度系统

为什么做：错误图片、弱相关图片和缺图会直接破坏专业感。

解决问题：入口页和详情页图片不稳定，部分分类卡产生空白。

用户价值：每张图都能被信任，并且知道来源与授权。

规则：

- 实体主图必须可追溯来源。
- 地图、档案、时间入口图只用本地已治理图片。
- 不适合做封面的图片可以保留为图集素材，但不能做入口封面。
- 缺图时不占用大图位，用文本占位或紧凑卡片。

## 3 个月路线

### P0

1. 时间轴双模式：Narrative + Atlas。
2. 修复地图、档案、时间页空白和错位。
3. 新增关系 overlay 数据模型。
4. 建筑师页增加关系面板。
5. 建筑师与建筑页内容模板升级。

### P1

1. `/graph` 关系图谱页。
2. 风格详情页重做。
3. 3 条学习路径：
   - 从柯布西耶到日本现代主义
   - 从赖特到有机现代主义
   - 从文艺复兴到巴洛克
4. Wikidata / Wikipedia / Commons 外部 ID 对齐。

### P2

1. 可拖拽缩放时间线。
2. 经纬度地图可视化。
3. 公开 GraphQL / SPARQL-like 查询接口。
4. 用户收藏和课程路径。
