# Learning Layer Building Template

Generated: 2026-06-09

Scope: learning-layer content model for building pages. No database changes, no taxonomy changes, no metadata changes.

Goal: turn a building page from a database record into a learning page by adding a consistent "Why Study This?" layer.

## Template

### Why Study This?

1. **One-sentence value**
   - What does this building teach in one sentence?
2. **Core question**
   - What architectural problem does the building make visible?
3. **What to observe**
   - What should a student look at first: plan, section, light, structure, material, site, circulation, facade, program, or urban role?
4. **Compare with**
   - Which buildings help clarify this one by similarity or contrast?
5. **Next reading**
   - What should the student read after this: architect page, type page, style page, period page, glossary term, building code topic, or another building?

## 20 Best Examples

### 1. Row House in Sumiyoshi

Architect: Tadao Ando
Current page slug: `row-house-sumiyoshi`

**One-sentence value**
A tiny concrete house that teaches how absence, courtyard, and daily movement can become architecture.

**Core question**
How can a very narrow urban house create a powerful spatial experience without relying on comfort or ornament?

**What to observe**
Observe the split plan, open courtyard, exposed circulation, concrete enclosure, and the way weather becomes part of domestic life.

**Compare with**
Villa Savoye, House NA, and Can Lis.

**Next reading**
Read Tadao Ando's architect page, then compare residential works by type and study the idea of courtyard houses.

## How To Use This Layer On Pages

Use this content as a first editorial layer, not as final academic text. The best placement is near the top of a building page after the hero/meta section and before deeper article sections. It should act as a student-facing orientation card:

- "Why this matters"
- "What problem it solves"
- "What to observe"
- "What to compare"
- "Where to go next"

The key product rule: every important building page should teach the user how to look before asking them to read more.
