## Easiest blockers to solve

1. **Missing definition**: highest editorial ROI; many terms already have clear category and source references.
2. **Translation uncertainty**: efficient batch work if handled with a terminology style guide.
3. **Duplicate ambiguity**: small set; resolve by canonical naming decisions.
4. **Category ambiguity**: moderate effort; requires taxonomy judgment but little source work.
5. **Requires technical review**: valuable but slower, especially code, structure, and materials.
6. **Source uncertainty and context-dependent phrase**: lower immediate ROI because source authority or standalone value must be rebuilt.
