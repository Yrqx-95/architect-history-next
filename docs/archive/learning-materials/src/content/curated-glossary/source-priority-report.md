# Source Priority Report

Future source recommendations are based on current curation coverage, not new scanning.

| Rank | Source type | Expected glossary yield | Expected educational value | Expected duplication risk | Expected review workload |
| --- | --- | --- | --- | --- | --- |
| Highest value | Building Materials Textbooks | High: materials, finishes, envelope, durability, sustainability. | High: directly supports student and practical learning. | Medium: concrete terms already exist, but many material families are absent. | Medium: definitions need technical precision but sources are usually stable. |
| Highest value | Structural Design Textbooks | High: load path, lateral systems, foundations, seismic basics. | High: closes a core architecture education gap. | Medium: structure backlog exists, but many concepts are still missing. | High: requires careful technical review. |
| Highest value | Environmental Systems Textbooks | Very high: HVAC, ventilation, daylight, thermal comfort, energy. | Very high: current pool has a critical gap. | Low: little overlap in current data. | High: technical concepts need authoritative review. |
| High value | Accessibility / Universal Design Standards | High: barrier-free glossary cluster and practical checklists. | Very high: essential for modern design learning. | Low: mostly absent now. | High: must use current code/standards carefully. |
| High value | Construction Technology Books | Medium-high: methods, sequencing, QA, site vocabulary. | High: bridges school knowledge and practice. | Medium: some construction terms exist. | Medium-high: process definitions need examples. |
| High value | Interior Design Books | High: programming, finishes, FF&E, presentation workflow. | High: supports a new product direction. | Low-medium: current interior coverage is thin. | Medium: terminology and taste labels need curation. |
| High value | Lighting Design Books | High: fundamentals currently underrepresented. | High: useful for interiors and environmental design. | Medium: existing lighting candidates include many product names. | Medium: technical plus design review. |
| Medium value | Furniture Design References | Medium: ergonomics, typology, specification vocabulary. | Medium-high: valuable for interiors but narrower. | Medium: product/name duplication risk. | Medium: distinguish concept from product/entity. |
| Medium value | Exam Preparation Books | High term yield. | Medium: useful if separated from prompt wording. | High: many current B terms already appear exam-derived. | High: needs verification against independent sources. |
| Medium value | Architectural History Books | Medium: current history pool is already strong. | High for archive depth, medium for glossary balance. | High: many proper names/entities rather than glossary concepts. | Medium: entity/glossary boundary work. |
| Low value | Product Catalogs | Low-medium: product names, dimensions, lighting/furniture labels. | Low unless converted into concept-level lessons. | Very high: current C-grade shows brand/product risk. | High: lots of filtering and rights/source caution. |

## Recommendation

Prioritize sources that create missing conceptual spines rather than sources that add many names. The best next imports are environmental systems, accessibility, structural design, and materials. Product catalogs should be delayed until Archistory has a separate product/entity model and stricter rights-aware review rules.
