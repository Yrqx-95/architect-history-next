# Knowledge Gap Action Plan

This 90-day roadmap uses only current curation reports and existing data. It should guide future work without triggering new OCR, scanning, routes, or public UI exposure.

## Next 30 days

Focus: core glossary, learning paths, required terms, building-learning mapping.

- What to build: finalize Core 100, edit the promotion-ready terms, refine learning path sections, review the 30 building-learning mappings.
- Files to touch: `src/content/core-learning-terms/`, `src/content/curated-glossary/`, `src/content/learning-product/`, `src/content/building-learning-map/`.
- What not to touch: homepage, navigation, routes, database schema, public glossary wiring.
- Expected user impact: creates the learning skeleton for future release.
- Risk level: low.

## Days 31-60

Focus: materials, structure, drawing, construction.

- What to build: review technical B-grade terms, write definitions for core structural/material terms, add drawing/documentation vocabulary, create construction sequence clusters.
- Files to touch: staged content files and reports only until review is complete.
- What not to touch: source importers, OCR scripts, production routes.
- Expected user impact: turns Archistory into a credible student knowledge base.
- Risk level: medium because technical terms require accuracy review.

## Days 61-90

Focus: interior design, lighting, accessibility, environmental systems, acoustics.

- What to build: define new glossary clusters, source priority brief, accessibility and environmental term lists, lighting fundamentals, acoustics basics.
- Files to touch: new staged content folders and style guide updates.
- What not to touch: product catalogs, brand registries, user accounts, AI features.
- Expected user impact: closes the largest product gaps and differentiates Archistory from a history-only archive.
- Risk level: medium-high because several areas require authoritative sources and careful terminology.
