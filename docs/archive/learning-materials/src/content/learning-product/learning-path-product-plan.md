# Learning Path Productization Plan

Goal: turn the existing archive, learning topics, public glossary, and curated outputs into a usable product structure without creating UI.

## Path summary

| Path | Launch status | Highest-value next action |
| --- | --- | --- |

| Architecture Student | partially-blocked | Use Core 100 as the required vocabulary spine. |

## Which paths can be launched now?

- Absolute Beginner
- Architecture History Explorer

These can start as editorial guide structures because they rely mostly on existing archive and glossary concepts.

## Which paths are blocked?

- Second-Class Architect Candidate is blocked by official-source and exam-boundary review.
- Interior Design Student is partially blocked by missing color, finish, lighting, and accessibility vocabulary.
- Architecture Student is partially blocked by missing environmental systems and detail drawing coverage.

## Highest ROI path

Architecture Student has the highest ROI because it connects the archive, Core 100 terms, code topics, and building-learning map into one coherent product identity.

## Path details

### Absolute Beginner

- Target user: Curious users and first-year students who need a map of architecture vocabulary.
- What the user will learn: How to read buildings through site, plan, section, structure, material, and historical context.
- Estimated time: 6-8 hours
- Next action: Launch as a text-only learning guide using existing archive links.
- Missing content: intro diagrams, section/elevation glossary terms, beginner checkpoints

### Architecture Student

- Target user: Architecture students who need reusable concepts for studio, history, and technical classes.
- What the user will learn: Core planning, drawing, structure, materials, and building-code concepts.
- Estimated time: 20-30 hours
- Next action: Use Core 100 as the required vocabulary spine.
- Missing content: detail drawing terms, steel/timber systems, environmental systems

### Second-Class Architect Candidate

- Target user: Learners preparing for Japanese architecture licensing study.
- What the user will learn: How to read high-frequency code and planning concepts without reducing the product to a quiz site.
- Estimated time: 30-40 hours
- Next action: Keep as internal structure until official-source review is stronger.
- Missing content: current official legal verification, exam concept boundaries, worked examples

### Interior Design Student

- Target user: Interior and architecture students learning human scale, furniture, lighting, and finishes.
- What the user will learn: Human dimensions, movement, furniture layout, lighting basics, and interior style vocabulary.
- Estimated time: 12-18 hours
- Next action: Build after glossary review of furniture and lighting terms.
- Missing content: color theory, finish schedules, lighting fundamentals, accessibility

### Architecture History Explorer

- Target user: Users entering through architects, works, styles, and periods.
- What the user will learn: How styles, typologies, and historical movements connect to buildings in the archive.
- Estimated time: 15-25 hours
- Next action: Launchable as a guided archive path with glossary support.
- Missing content: style criteria, regional bridge essays, entity/glossary separation
