# Archistory Phase 2 Learning Audit

## Coverage

### Code Topics

All 8 current Code Topics are represented in the learning graph:

- zoning-districts
- building-coverage-ratio
- floor-area-ratio
- road-access-obligation
- road-slant-restriction
- north-side-slant-restriction
- fire-prevention-district
- quasi-fire-prevention-district

Each topic now has:

- learning stage
- difficulty
- estimated study minutes
- required glossary terms
- required topics
- next topics
- related topics
- exam concepts
- learning objectives
- common confusions
- 30-second / 3-minute / 10-minute review data

High-value glossary coverage exists for:

- area controls

- Absolute Beginner
- Architecture Student

- topic order

- estimated study time

- source references

## Learning Gaps

Primary learning-system gaps remaining:

- No visible next-topic UI yet.
- No visible path UI yet.
- No exam-mode UI yet.
- Search does not yet consume alias and concept data.
- Glossary does not yet expose required-term hierarchy.

These are intentional. Phase 2 created the internal foundation first.

## Recommendation

The next product step should be a small visible integration:

1. Required Terms block on Code Topic pages.
2. Recommended Next Topic block below Memory Tips.
3. Learning Path preview on Learn page.

Avoid adding new topics before the current graph becomes visible to learners.
